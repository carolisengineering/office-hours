# DS 510: Machine Learning

**Credits:** 3
**Prerequisites:** DS 501 **and** DS 505 (both are required)

DS 510 is the core machine learning course: supervised learning (linear models,
trees, ensembles, SVMs), unsupervised learning (clustering, dimensionality
reduction), model evaluation and cross-validation, regularization, the
bias-variance tradeoff, and practical feature engineering. Work is in Python with
scikit-learn.

Both prerequisites are enforced at registration. A student who has completed only
DS 501, or only DS 505, cannot register for DS 510. There is no petition to waive
either one.

DS 510 is itself a prerequisite for **DS 530: Deep Learning** and **DS 540: Natural
Language Processing**, and is one of the two named course requirements for the
**DS 599 Capstone** (along with DS 520).

Assessment: four graded checkpoints, a midterm modeling project, and a final
modeling competition. Offered every term.
