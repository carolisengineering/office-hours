# DS 502: Data Management and SQL

**Credits:** 3
**Prerequisite:** DS 500

DS 502 covers relational data modeling, SQL (joins, aggregation, window functions,
CTEs), schema design and normalization, indexing and query performance, and moving
data between files, databases, and dataframes. Students work with PostgreSQL. The
course also introduces basic data pipeline concepts and data quality checks.

DS 502 is the prerequisite for **DS 520: Data Visualization and Communication**.

Assessment: weekly SQL exercises, a database design project, and a final data
pipeline project. No exam. Offered every term.
