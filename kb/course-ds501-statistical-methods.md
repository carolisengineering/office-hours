# DS 501: Statistical Methods

**Credits:** 3
**Prerequisite:** DS 500

DS 501 covers inferential statistics for data science: estimation, confidence
intervals, hypothesis testing, resampling and the bootstrap, linear and logistic
regression, and common pitfalls (multiple comparisons, p-hacking, confounding).
Work is done in Python with statsmodels and scikit-learn.

DS 501 is one of the two prerequisites for **DS 510: Machine Learning** (the other
is DS 505). Students planning to reach DS 510 should take DS 501 and DS 505 as
early as possible, typically in the term right after DS 500.

Assessment: weekly problem sets, one midterm analysis report, one final analysis
report. Offered every term.
