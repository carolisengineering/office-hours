# DS 505: Linear Algebra for Machine Learning

**Credits:** 3
**Prerequisite:** DS 500

DS 505 is an applied linear algebra course aimed at machine learning: vectors and
matrices, matrix decompositions (LU, QR, eigendecomposition, SVD), projections and
least squares, norms and distances, and gradients. Concepts are taught alongside
NumPy implementations, with an emphasis on the geometry behind ML methods rather
than proofs.

DS 505 is one of the two prerequisites for **DS 510: Machine Learning** (the other
is DS 501). It is commonly taken in the same term as DS 501.

Assessment: weekly problem sets and a final project applying SVD to a real dataset.
Offered every term.
