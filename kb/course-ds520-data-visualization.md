# DS 520: Data Visualization and Communication

**Credits:** 3
**Prerequisite:** DS 502

DS 520 covers the principles of visual encoding, chart selection, color and
accessibility, dashboard design, and communicating quantitative findings to
non-technical audiences. Students build static and interactive visualizations in
Python (matplotlib, plotly) and produce a written analysis and a live presentation.

DS 520 is one of the two named course requirements for the **DS 599 Capstone**
(along with DS 510), so students should plan to finish DS 520 before their final
term.

Assessment: weekly critiques, a redesign project, and a final data story.
Offered every term.
