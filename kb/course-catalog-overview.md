# Course Catalog Overview

The Online M.S. in Data Science is 10 courses (3 credits each). Every course except
DS 500 has at least one prerequisite. Prerequisites are enforced at registration.

| Course | Title | Prerequisite(s) |
|---|---|---|
| DS 500 | Foundations of Data Science | None (gateway course) |
| DS 501 | Statistical Methods | DS 500 |
| DS 502 | Data Management and SQL | DS 500 |
| DS 505 | Linear Algebra for Machine Learning | DS 500 |
| DS 510 | Machine Learning | DS 501 **and** DS 505 |
| DS 520 | Data Visualization and Communication | DS 502 |
| DS 530 | Deep Learning | DS 510 |
| DS 540 | Natural Language Processing | DS 510 |
| DS 550 | Data Ethics and Governance | DS 500 |
| DS 599 | Capstone | 24 completed credits, including DS 510 and DS 520 |

## Typical sequence

- **Term 1:** DS 500, then DS 501 / DS 502 / DS 505 once DS 500 is complete.
- **Middle terms:** DS 510 (after DS 501 and DS 505), then DS 520, DS 530, DS 540,
  DS 550 in any order that satisfies prerequisites.
- **Final term:** DS 599 Capstone.

There is no way to waive a prerequisite by petition. Students who believe they have
equivalent preparation should discuss transfer credit with their success advisor.
