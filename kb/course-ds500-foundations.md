# DS 500: Foundations of Data Science

**Credits:** 3
**Prerequisite:** None. DS 500 is the gateway course and must be completed before
any other DS course.

DS 500 establishes the shared toolkit for the program: the Python data stack
(NumPy, pandas), working in Jupyter, version control with Git, reproducible
environments, and the data-analysis workflow from question to cleaned dataset to
summary. Students also cover basic probability, sampling, and how to read and
critique a data-driven claim.

Assessment is four graded checkpoints (weekly problem sets in weeks 3, 6, 9, 12)
and a final applied project. There is no exam.

Every incoming student takes DS 500 in their first term. It is offered every term.
