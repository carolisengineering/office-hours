# DS 540: Natural Language Processing

**Credits:** 3
**Prerequisite:** DS 510

DS 540 covers text processing, embeddings, language modeling, sequence labeling,
transformers, retrieval-augmented generation, and evaluation of language systems.
Students build and evaluate NLP pipelines in Python and work with open-source
models.

DS 540 is an elective; it is not required for the capstone. It may be taken in
either order relative to DS 530 once DS 510 is complete.

Assessment: four checkpoints and a final NLP application project. Offered in Fall
and Summer only (not Spring).
